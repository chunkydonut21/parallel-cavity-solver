05 / PARALLEL EXECUTION

OpenMP comparison

Run the same 65 × 65 cavity case with serial C++ and 1, 2, and 4 OpenMP threads. Compare the fields before comparing time.

Does adding threads reduce runtime?

Each version runs 100 timesteps, three times. The table uses median numerical runtime. Speedup is serial median divided by OpenMP median; efficiency divides speedup by thread count.

This experiment takes around half a minute on the current machine.

MPI comparison

METHOD

What is being compared

The Poisson benchmark uses a manufactured problem, so its numerical error can be checked. The cavity simulation tests the same solver as part of a larger program. The OpenMP and MPI experiments hold that workload fixed and check every saved field against serial. Timings come from this computer and should be repeated under controlled conditions before drawing hardware conclusions.
